# Neil Carlo Palacio — Portfolio

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Personalize

Edit `src/data/portfolio.ts` for:
- GitHub / LinkedIn / email
- projects and links
- skills
- experience
- project categories

Replace placeholder experience/statistics and project URLs before publishing.

The contact form currently performs client-side validation only. Connect it to Formspree, Resend, EmailJS, a server endpoint, or another form backend for real submissions.
